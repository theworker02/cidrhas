cidrhas

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

cidrhas [options] <ipv4> <cidr>
Tip: cidrhas --help prints this text in the terminal. cidrhas --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
<ipv4>Dotted-quad IPv4 address, for example 10.0.0.5
<cidr>IPv4 CIDR, for example 10.0.0.0/8

Exit codes

CodeMeaning
0Address is in the CIDR.
1Address is not in the CIDR, or inputs are invalid / missing.

Configuration

IPv4 only. Prefix length 0–32. Octets must be 0–255. Network bits are masked; host bits in the CIDR address are ignored.

Worked examples

Success path

cidrhas 10.0.0.5 10.0.0.0/8
echo exit:$?

Exit code is 0. Optional stdout: `inside`.

Failure path

cidrhas 8.8.8.8 10.0.0.0/8 ; echo exit:$?

Exit code is 1 (`outside`).

Bad input:

cidrhas not-an-ip 10.0.0.0/8

stderr: invalid ipv4. Exit 1.
